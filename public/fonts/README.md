# AgentCloud reference fonts

These unchanged WOFF2 assets were extracted from the user-supplied `AgentCloud Mockup v4.html` bundle. Hanken Grotesk provides headings; JetBrains Mono provides interface copy. Each font contains the reference’s variable weights; the application declares the 400–700 range used by its type tokens. Numbered files retain the original Unicode subsets, declared in `app/tokens.css` so the browser requests only the scripts needed by the page.

Both families use the SIL Open Font License 1.1. The accompanying license text comes from each family’s Google Fonts source directory:

- https://github.com/google/fonts/tree/main/ofl/hankengrotesk
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

No third-party font request is made at runtime.
